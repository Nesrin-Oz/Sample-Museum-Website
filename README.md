# Örnek Müze Web Sitesi (Sample Museum Website)

Bu proje, bir müze konsepti etrafında şekillendirilmiş, 50'den fazla statik HTML sayfasından oluşan kapsamlı bir ön yüz (frontend) çalışmasıdır.

## Özellikler
* **Geniş İçerik Ağacı:** Müze koleksiyonları, tarihi eser sergileri, ziyaret planlaması ve bilgi formları için birbirine bağlı 50+ statik sayfa yapısı.
* **Bağımsız Mimari:** Saf HTML ve CSS kullanılarak oluşturulmuş arayüz tasarımı.
* **Kurumsal Tasarım:** Ziyaretçi deneyimine ve kurumsal standartlara uygun gezinme menüleri ile içerik yerleşimi.
